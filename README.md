# Sales Performance Dashboard

## Project Overview
This project analyses sales data using Microsoft Excel. The dashboard provides insights into revenue, orders, product performance, and regional sales.

## Tools Used
- Microsoft Excel
- Excel formulas
- Pivot-free data analysis
- Charts and visualisations

## Excel Skills Demonstrated
- SUM
- COUNTA
- AVERAGE
- MAX and MIN
- SUMIF
- Data analysis
- Dashboard creation
- Data visualisation

## Dashboard KPIs
- Total Revenue: R148,650
- Total Orders: 20
- Average Order Value: R7,432.50
- Highest Sale: R24,000
- Lowest Sale: R1,250

## Project Sheets
1. Sales_Data – Raw sales records.
2. Sales_Summary – Product and regional sales analysis.
3. Dashboard – KPI values and charts.

## Key Learning Outcome
Developed practical Excel skills by transforming raw sales data into meaningful business insights through formulas, calculations, and visualisations.
